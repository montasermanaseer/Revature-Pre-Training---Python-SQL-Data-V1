# Lab: Transactions Analysis

Run the lab script to load, clean, and analyze transactions then store them in SQLite.

Prerequisites

- Python 3.8+
- Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run

```bash
python src/main/lab.py
```

Output

- The script prints the results of seven SQL queries to the console.
- After running, take a screenshot of the console output and include it in the lab folder for submission.
